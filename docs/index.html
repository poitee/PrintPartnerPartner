Get started

One Docker container serves the API and UI on port 8080. Your data stays in a local volume.

git clone https://github.com/poitee/PrintPartnerPartner.git
cd PrintPartnerPartner
docker compose pull && docker compose up -d

Open localhost:8080, add a source, then create a build with Create build or Manage builds.

Workflow

  • Sources — GitHub, local folders, or zips; categories; import rules; STL search; update badges.
  • Build — attach layers, pick files, role filament colors (live previews), Update build, share or export.
  • Review — validation by role and filament, 3D previews, quantity edits, Export STLs.
  • Checkoff — per-unit progress, printable checklist, export missing STLs.
