Print Partner

Self-hostable desk workflow for layered STL kits — sync repos, compose a plan, pack plates, export, and check off prints. Attach Cursor / Grok / Claude over HTTP MCP (no in-app Kit Advisor).

Get started (LAN Docker)

One Docker container serves the API and UI on port 8080. Your data stays in a local volume.

git clone https://github.com/poitee/PrintPartnerPartner.git
cd PrintPartnerPartner
docker compose pull && docker compose up -d

Open localhost:8080 on the host, or http://<lan-ip>:8080 from another machine on your network. Add a source on Library, then create a Build with New Build or Builds.

Desk loop

  • Library — GitHub, local folders, or zips; categories; import rules; STL search; update badges.
  • Builds — list-first home. New Build asks only for a name and opens Sources.
  • Sources — attach sources, picks, and roles for this Build.
  • Plan — quantities, warnings, saved draft, then explicit Apply.
  • Checkoff — per-unit progress, assembled toggles, printable checklist.
  • Production — plates, downloads, slicer handoff, and printer send. Global Production lists jobs across Builds.

Optional: Spoolman, Moonraker/PrusaLink/Bambu status, Discord digest, Home Assistant, slicer sidecar — see the README.

MCP attach (kit brain)

There is no in-app Kit Advisor and no Settings → AI. Connect Cursor, Grok, or Claude to streamable HTTP MCP at /api/v1/mcp with PRINT_PARTNER_API_KEY. Mutations stay confirm-to-apply.
